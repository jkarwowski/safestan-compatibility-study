You are translating a single Stan model into SafeStan for a regression-test
corpus. The goal is not to make the model "nicer"; the goal is to decide
whether the original posterior/log density can be represented under SafeStan
restrictions with no change or only a small mechanical rewrite. Return only the
structured JSON requested by the caller.

Work method:

1. Identify the observed/protected data variable(s) scored by the likelihood.
2. Separate protected data-context uses from value-context computations.
   Parameters, transformed parameters, and deterministic parameter expressions
   are value-context terms; they are not protected observations.
3. Check whether the protected data variables already satisfy SafeStan's
   syntactic discipline.
4. If not, look for a same-density mechanical rewrite.
5. If the rewrite would require changing the statistical model, replacing a
   marginalized latent-state algorithm, or changing the likelihood, classify
   the case as `major`.
6. For `as-is` and `minor`, output complete files. Do not output patches.

SafeStan rules to apply:

- Only protected observed data are subject to SafeStan's data-context
  restrictions. Parameters live in the value context. Missing explicit priors,
  implicit Stan priors, or parameter use before a prior statement are not
  SafeStan compatibility failures by themselves.
- Protected observed data should appear as top-level data variables and be
  observed by plain `name ~ distribution(...)` sampling statements.
- Do not use `target +=`, `target()`, direct `_lpdf`/`_lpmf` scoring, or
  user-defined probability distributions for protected observations.
- Do not use protected data in `transformed data` or before its observation.
  If a summary/reshape is needed, add deterministic fields to `data_safe_json`
  and document them.
- Avoid sampling statements inside loops or conditionals when the same density
  can be expressed as one vectorized sampling statement.
- Do not add priors solely to satisfy SafeStan. Adding priors changes the
  posterior unless the original program already had the exact same density
  contribution.

Compatibility labels:

- `as-is`: the original Stan program is already SafeStan-compatible. Return
  `model_safe_stan` equivalent to the original and `data_safe_json` equivalent
  to the original data.
- `minor`: a same-posterior SafeStan version can be produced using only
  mechanical changes such as vectorizing simple likelihoods or adding
  deterministic data copies/reshapes.
- `major`: no SafeStan version can be produced without a substantive model or
  density change. In this case return empty strings for `model_safe_stan` and
  `data_safe_json`.

Requirements:

- Never invent new observations or synthetic data.
- `data_safe_json` must be a valid JSON object string. It may equal the original
  data exactly, or be a deterministic augmentation/reshape of it.
- If you add fields to `data_safe_json`, document the exact deterministic
  relation in `safety_note_md`.
- Preserve the intended posterior/log density for AS-IS and MINOR.
- If the model relies on mixture marginalization, custom manual scoring,
  censored/truncated target adjustments, or hidden-state algorithms for
  protected observations, classify it as `major`.
- Do not classify a model as `major` merely because parameters have implicit or
  improper priors. That is a value-context issue, not a protected-data-context
  issue for this compatibility task.
- `safety_note_md` must be Markdown beginning with `# SafeStan Safety Note` and
  include: compatibility, protected data choice, generated files, and a concise
  explanation of any change.

Original `model.stan`:

```stan
data {
  int<lower=1> N;
  vector[N] x;
  vector[N] y;
}
parameters {
  real alpha_linear;
  real beta_linear;
  real<lower=0> sigma_linear;
  real alpha_quad;
  real beta_quad;
  real gamma_quad;
  real<lower=0> sigma_quad;
  real<lower=0, upper=1> p_linear;
}
model {
  alpha_linear ~ normal(0, 5);
  beta_linear ~ normal(0, 5);
  sigma_linear ~ lognormal(0, 1);
  alpha_quad ~ normal(0, 5);
  beta_quad ~ normal(0, 5);
  gamma_quad ~ normal(0, 5);
  sigma_quad ~ lognormal(0, 1);
  p_linear ~ beta(1, 1);
  {
    real lp_linear = log(p_linear);
    real lp_quad = log1m(p_linear);
    for (n in 1 : N) {
      lp_linear += normal_lpdf(y[n] | alpha_linear + beta_linear * x[n], sigma_linear);
      lp_quad += normal_lpdf(y[n] | alpha_quad + beta_quad * x[n]
                                    + gamma_quad * square(x[n]), sigma_quad);
    }
    target += log_sum_exp(lp_linear, lp_quad);
  }
}
generated quantities {
  real posterior_linear_prob;
  {
    real lp_linear = log(p_linear);
    real lp_quad = log1m(p_linear);
    for (n in 1 : N) {
      lp_linear += normal_lpdf(y[n] | alpha_linear + beta_linear * x[n], sigma_linear);
      lp_quad += normal_lpdf(y[n] | alpha_quad + beta_quad * x[n]
                                    + gamma_quad * square(x[n]), sigma_quad);
    }
    posterior_linear_prob = exp(lp_linear - log_sum_exp(lp_linear, lp_quad));
  }
}
```
